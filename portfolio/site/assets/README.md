# assets

Fotografías y key visuals de los casos.

Mientras esta carpeta esté vacía, cada caso usa una placa generada con CSS.
Para sustituirla por una foto real, añade `--img` a la placa del caso en
`index.html` (ver README del portfolio):

```html
<div class="plate plate--betlink" style="--img:url('assets/betlink-01.jpg')">
```
